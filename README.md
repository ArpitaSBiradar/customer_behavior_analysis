# Customer Shopping Behavior Analysis

## Overview
This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, sales trends, and subscription behavior. The goal is to transform raw data into meaningful insights that support data-driven business decisions.

## Dataset
- **Records:** 3,900 customer purchases
- **Features:** 18 columns
- **Includes:** Customer demographics, purchase details, discounts, shipping preferences, ratings, and subscription status.

## Tools & Technologies
- **Python:** Data loading, cleaning, EDA, and feature engineering
- **Pandas:** Data manipulation and analysis
- **SQL:** Business queries and data analysis
- **PostgreSQL:** Database integration and querying
- **Power BI:** Interactive dashboard and visualization
- **Gamma:** Project presentation
- **Jupyter Notebook:** Python-based analysis

## Project Workflow
1. **Data Loading:** Imported the dataset into Python using Pandas.
2. **EDA:** Explored data structure, summary statistics, and customer purchase patterns.
3. **Data Cleaning:** Handled missing values, standardized column names, and created new features.
4. **Database Integration:** Loaded the cleaned dataset into PostgreSQL.
5. **SQL Analysis:** Analyzed revenue, customer segments, product ratings, discount usage, and subscription trends.
6. **Dashboard Development:** Built an interactive Power BI dashboard to visualize key findings.
7. **Reporting:** Prepared a project report summarizing the analysis and business insights.
8. **Presentation:** Created a project presentation using Gamma.

## Dashboard
The Power BI dashboard presents key insights into:
- Revenue by gender and age group
- Subscriber vs. non-subscriber spending
- Top-rated and best-selling products
- Discount and shipping behavior
- Customer segmentation and repeat purchases

## Key Results
- Identified purchasing patterns across customer segments.
- Compared revenue and spending across demographic groups.
- Analyzed the relationship between discounts and purchasing behavior.
- Evaluated subscription trends and repeat customer activity.
- Developed recommendations for customer retention, targeted marketing, and subscription growth.

## Business Recommendations
- Introduce loyalty programs to encourage repeat purchases.
- Promote subscription benefits to increase customer engagement.
- Optimize discount strategies to balance sales and profitability.
- Highlight popular and highly rated products in marketing campaigns.
- Target high-value customer segments with personalized promotions.

## How to Run

### 1. Clone the Repository
```bash
git clone <your-repository-url>
cd <your-repository-folder>
```

### 2. Install Dependencies
```bash
pip install pandas numpy matplotlib seaborn sqlalchemy psycopg2-binary jupyter
```

### 3. Run the Python Analysis
Open Jupyter Notebook and run the notebook containing the data loading, EDA, and cleaning steps.

```bash
jupyter notebook
```

### 4. Configure the Database
- Install and start PostgreSQL.
- Create a database for the project.
- Update the database connection credentials in your Python script.
- Run the SQL queries provided in the repository.

### 5. Open the Power BI Dashboard
Open the `.pbix` file in Power BI Desktop. Configure the data source if required.
